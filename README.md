# AI Personal Assistant

A web-based AI personal assistant built with Flask and the OpenAI Responses API.

The application allows users to ask questions and summarize emails through a simple, responsive web interface.

## Features

- Ask questions and receive AI-generated responses
- Summarize emails using AI
- Flask backend with separate API routes
- Responsive web interface
- Asynchronous frontend requests using JavaScript Fetch API
- Secure API-key management using environment variables
- JSON-based responses between frontend and backend
- Loading states and error handling

## Tech Stack

### Backend

- Python

- OpenAI API

### Frontend
